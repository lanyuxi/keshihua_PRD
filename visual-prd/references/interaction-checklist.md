# 原型与容器自检

先运行 `node scripts/check-interactions.js <原型 HTML 文件>`。静态检查不能代替真实浏览器操作；逐项检查可见 DOM、路由、状态、标注定位和控制台。任何一项失败须修复并重新检查。报告记录测试对象、时间、实际结果和修复记录；没有相应控件或语法的项目标记“不适用/未覆盖”，不得冒充通过。

## 导航类

- [ ] 主导航每一项点击后能切换到对应页面
- [ ] 页面内“查看详情”“返回”等按钮能正确跳转
- [ ] 列表进入详情时，URL/route params 携带当前记录 ID，详情页显示的上下文与所点记录一致
- [ ] 浏览器前进/后退能正确切换页面

## 切换类

- [ ] 项目包含评审场景时，切换至少两个场景，下拉框选中 ID/名称与原型实际状态一致，切页与重新载入后仍同步；无场景控件标记不适用
- [ ] Tab 点击后内容区正确切换
- [ ] 步骤条点击后能跳到对应步骤
- [ ] 开关/单选/多选点击后状态变化且视觉更新

## 弹层类

- [ ] 所有“新建”“编辑”“查看”按钮能打开对应弹层
- [ ] 弹层内“取消”“关闭”“确定”能正确关闭
- [ ] ESC 键和点击遮罩能关闭最顶层弹层

## 表单类

- [ ] 输入框输入后 state 同步更新
- [ ] 表单提交有反馈（成功 Toast 或错误提示）
- [ ] 创建成功后目标列表真实新增一条记录，刷新后仍保留；不得只关闭弹层和显示 Toast
- [ ] 创建完成后草稿被清空，再次打开创建弹层不会残留上次输入
- [ ] 必填项为空时显示校验错误

## 列表类

- [ ] 筛选条件切换后列表内容更新
- [ ] 搜索框输入后列表实时过滤
- [ ] 排序点击后列表顺序变化
- [ ] 每个可排序字段在所有列表行上都有对应 `data-<key>` 数据源

## 状态类

- [ ] 空状态、加载状态、错误状态有对应展示
- [ ] 操作后相关数据区域自动重绘

## 构建模式边界

- [ ] 装配模式没有重写现有 PRD、原型或标注源文件
- [ ] 增强模式只在输出目录生成副本，没有无条件注入第二套交互运行时
- [ ] 生成模式的 PRD、标注和原型均来自同一产品模型
- [ ] 未提供界面规范的旧产品模型仍可正常构建

## 评审模式与交付身份

- [ ] `build-report.json` 存在 `primary_artifact`，且指向实际交付的 `visual-prd.html`
- [ ] 主交付中同时存在三栏评审和浮动标注模式，不是另行手写的缩减容器
- [ ] 点击“切换为浮动标注”后左右侧栏与拖拽条隐藏，中间原型自动扩展
- [ ] 点击“切换为三栏评审”后两侧栏恢复，宽度与标注位置正确重算
- [ ] 刷新页面后保留上次评审模式
- [ ] `python3 scripts/validate-review-artifact.py <visual-prd.html>` 返回 PASS

## 界面规范（仅生成模式且提供配置时）

- [ ] `ui-profile.json` 通过 `validate-ui-profile.py`
- [ ] 筛选器、列表、按钮、Tab 和弹层使用配置的组件形态
- [ ] 默认、选中、禁用、错误、焦点、加载和空状态均可辨识
- [ ] 组件变体没有改变 `data-action`、字段模型或标注锚点
- [ ] `ui-profile-preview.html` 离线可打开且不请求外部资源
- [ ] `visual-prd.html` 顶部有“界面规范”入口，可打开、关闭并用 ESC 退出
- [ ] 筛选器、列表、Tab、按钮和弹层切换后中间原型立即可见更新
- [ ] “当前页面”覆盖不污染其他页面，页面切换后正确重算有效规范
- [ ] 全局值被当前页面覆盖时有明确提示；产品模型显式锁定的组件在页面范围内禁用或标记为“部分生效”
- [ ] 越界数值不会写入 CSS；品牌文字、主文字与背景的对比度均不低于 4.5:1
- [ ] 列表结构（表格/卡片）与列表密度（舒适/紧凑）独立设置，不出现“紧凑列表 + 舒适密度”的矛盾状态
- [ ] 刷新后从 `localStorage` 恢复预览配置
- [ ] 本地草稿按 profile id 隔离；损坏、跨 profile 或校验失败的草稿不会覆盖新配置
- [ ] 导出的 `ui-profile.json` 通过 `validate-ui-profile.py` 且可重建同样的组件形态
- [ ] 抽屉打开后焦点不会离开抽屉，关闭后焦点回到原入口
- [ ] 移动端宽度下无关键控件溢出或遮挡

## 编号一致性

- [ ] 每个标注的编号在原型圆点和右侧面板中完全一致
- [ ] 编号只来源于标注数据的 `order` 字段，没有第二处独立计算
- [ ] 同一时刻可见的标注编号从 1 开始连续，无跳号、无重号
- [ ] 跨页面标注进入页面基础序列，页面内标注顺延且不冲突；顶层弹层独立编号
- [ ] 运行时断言开启，控制台无编号不一致警告

## 标注联动

- [ ] 鼠标移入和移出标注圆点时位置稳定，不重复重绘或闪动
- [ ] 点击右侧标注条目后，中间原型自动打开相同 `data-anno` 的标注详情
- [ ] 右侧条目支持 Enter 和空格键打开对应标注

## 产品说明自动保存

- [ ] 产品说明输入后直接失焦、切换预览或栏目，最终内容保留；左栏无重复的手动保存入口
- [ ] 授权后等待顶部已自动写回，检查实际 HTML，并在无缓存上下文重新打开确认内容；未授权只显示草稿状态

## Markdown 渲染完整性

执行前读取 [Markdown 渲染指南](markdown-render-guide.md)。

- [ ] 表格渲染为 HTML `<table>`，不是原始 Markdown 文本
- [ ] 标题层级正确，无跳级
- [ ] 列表渲染为 `<ol>`/`<ul>`
- [ ] 代码块渲染为 `<pre><code>`，且保留缩进
- [ ] 行内代码、加粗、斜体、引用块均正确渲染
- [ ] 表格前后有空行，不会因缺空行被解析为段落
- [ ] 测试文档实际包含以上每种语法；未覆盖的语法不得标记为通过

## 指标与埋点（仅适用时）

- [ ] `metrics.json` 通过 `python3 scripts/validate-metrics.py <metrics.json>`
- [ ] 已确认指标的公式、统计窗口、去重和数据来源均有依据
- [ ] 比率指标有明确分子与分母，事件引用能命中实际事件
- [ ] 待确认项没有被写成已确认或可计算

完成后在最终离线 HTML 上复测适用项目，并确认没有外部资源请求、未处理异常或编号警告。
