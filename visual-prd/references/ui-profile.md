# 界面规范配置

`ui-profile.json` 是生成模式的可选视觉输入。它不保存需求、规则、数据或验收条件，不是第二份业务事实源。

## 适用范围

- 适用于 `build-prototype.py` 生成的声明式组件。
- 已有 HTML 默认保留自身样式；除非用户明确授权，不得把配置转换为全局 CSS 覆盖现有页面。
- 特殊业务组件仍需 `custom` 或单独适配。

## 输入优先级

从可靠到不确定依次为：

1. 现有设计变量、组件规范或本地 CSS；
2. 可检查的现有页面；
3. 页面截图；
4. 用户自然语言描述；
5. 内置中性评审样式。

从截图推断的数值须标记为近似，不承诺一比一复刻。

## 配置范围

从 `assets/ui-profile-template.json` 创建配置。支持：

- 语义颜色、字体、字号、行高；
- 控件、面板、弹层圆角；
- 页面、面板、控件和组件间距；
- 面板与弹层阴影强度；
- 筛选器的下拉、分段和标签形态；
- 表格和卡片两种列表结构，以及独立的舒适/紧凑密度；旧版 `variant: compact` 会迁移为 `variant: table` + `density: compact`；
- 下划线、胶囊和分段 Tab；
- 按钮尺寸；
- 对话框尺寸和抽屉宽度。
- `page_overrides.<pageId>` 中的页面级 tokens 和组件覆盖。

颜色和组件状态通过语义变量统一派生。页面组件只声明必要的 `appearance` 覆盖，禁止重复整段 CSS。

## 校验与预览

```bash
python3 scripts/validate-ui-profile.py ui-profile.json
python3 scripts/build-ui-preview.py ui-profile.json --output ui-profile-preview.html
```

预览至少检查默认、悬停、选中、禁用、错误、焦点、加载和空状态。自定义字体仅允许本机可用字体栈；不得引用远程字体或外部资源。

## 可视化配置器

使用界面规范构建后，`visual-prd.html` 顶部显示“界面规范”入口。配置器支持：

- 实时切换筛选器、列表、Tab、按钮和对话框形态；
- 调整常用颜色、圆角和间距；
- 在“全局默认”和“当前页面”之间切换；
- 自动保存到当前浏览器的 `localStorage`；
- 导出完整 `ui-profile.json`，供后续构建重用。

配置器会在修改时校验数值范围和关键配色对比度；品牌文字、主文字与背景的对比度低于 4.5:1 时不会应用或导出。全局值被当前页面覆盖、组件不存在或被产品模型的 `appearance` 固定时，字段会显示原因，避免“改了但看不出变化”。本机草稿按 profile id 隔离，无效或不兼容草稿会被忽略。

离线 HTML 不能在未授权的情况下直接改写原配置文件。因此“导出 JSON → 替换项目配置 → 重新构建”是可复现的正式回写路径。

优先级为：组件 `appearance` 显式覆盖 > `page_overrides` > 全局 `components`。可视化配置器只编辑后两层，不改变产品模型里的业务事实。当前页面全部被 `appearance` 固定的组件字段会禁用；部分固定时仍可修改未固定组件，并明确标记“部分组件已固定”。

## 能力边界

- 配置目的是减少评审中的组件偏差，不替代专业视觉设计。
- 结构变体只覆盖高频组件；复杂画布、富文本、地图、行业控件和复杂图表需单独实现。
- 更换配置不能改变 `data-action`、`data-anno`、字段模型或业务规则。
