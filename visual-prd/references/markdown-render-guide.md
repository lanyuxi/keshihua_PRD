# Markdown 渲染指南

## 支持范围

PRD 文档区必须支持并在最终 DOM 中验证：GFM 表格、`h1`–`h6`、加粗、斜体、有序/无序列表、围栏代码块、行内代码、引用块和分割线。

- 使用 marked.js 时配置 `{ gfm: true, breaks: false }`。
- 使用 markdown-it 时启用 `.enable('table')`。
- 使用自定义离线解析器时，至少实现表格、代码块、列表和上述行内语法；不得把它描述成完整的第三方库实现。

## 表格预处理

渲染前在内存副本中为表格块补齐前后空行，不改变用户保存的 Markdown 原文。表格块须满足：

1. 表头及后续行连续以 `|` 开头。
2. 第二行为分隔行，每个单元格匹配 `:?-{3,}:?`。
3. 表格块上一行、下一行不是空行时，仅在渲染副本中插入空行。

## 安全与编辑

- Markdown 源码在识别语法前先进行 HTML 转义；默认不执行原始 HTML、事件属性或脚本。
- 链接只允许明确支持的协议，外部链接使用 `rel="noreferrer noopener"`。
- 编辑区保存原始 Markdown，预览区保存渲染结果；不得把预览 HTML 反写为 Markdown。
- 输入自动保存到 IndexedDB 草稿；授权后自动写回 HTML。草稿不等于磁盘保存，详见 [编辑与导出指南](editing-and-export.md)。
- 图片采用 `![说明](data:image/png;base64,...)` 等内嵌 data URI；支持 PNG、JPEG、GIF、WebP 和 SVG 图像。粘贴的位图自动转换为 data URI。原始 HTML 不作为图片编辑方式。
- `mermaid` 围栏代码块在预览时由内嵌 Mermaid 库渲染为 SVG，编辑与磁盘保存保留原始 Markdown 源码；普通代码块仍显示为代码。
- Mermaid 初始化使用 `startOnLoad: false` 和 `securityLevel: "strict"`，不执行图中的点击回调或原始脚本；语法错误显示提示和源码，允许继续编辑。渲染过程不请求网络。

## 样式要求

- 表格使用可见边框、表头背景、单元格内边距，并在窄栏中允许横向滚动。
- 代码使用等宽字体，代码块保留空格和换行。
- 引用块使用左边框；行内代码与正文形成清晰但克制的对比。

## 自检方法

以最终交付 HTML 的实际 DOM 为准，不只检查 Markdown 源码。测试文档必须主动包含所有支持语法；某种标签数量为零只能说明“未覆盖”，不能判定为通过。

| 语法 | 必须出现的 DOM |
| --- | --- |
| 表格 | `table > thead` 与 `table > tbody` |
| 标题 | 对应层级的 `h1`–`h6` |
| 加粗/斜体 | `strong` / `em` |
| 列表 | `ol` / `ul` |
| 代码块 | `pre > code` |
| 行内代码 | 非 `pre` 后代的 `code` |
| 引用块 | `blockquote` |
| 分割线 | `hr` |

流程图另检查 `.mermaid-diagram > svg`：修改节点/连线后重新预览，确认图与文字描述一致；语法错误必须保留可恢复的源码。
