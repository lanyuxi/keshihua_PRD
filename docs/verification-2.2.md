# 流程图格式修改验证 · 2.2.0

## 修改结果

流程图的源数据改为 Markdown 中的 Mermaid 围栏代码块。编辑区显示 `graph TD`、节点、`-->` 连线、`|条件|` 分支和 `%%` 注释，预览区离线渲染 SVG。业务流程、核心功能流程和数据流继续配套可编辑的文字说明。技能说明、容器和构建脚本一并更新。

原先把 SVG 编码为图片引用，导致编辑区展示长串 base64，而无法方便修改节点。现在保存的是原始 Markdown 源码，渲染后的 SVG 仅用于预览，不作为持久化编辑源。

## 使用

打开 [演示文件](../examples/visual-prd-demo.html)，点击“流程图 → 编辑”，直接改源码和说明；点击“预览”查看结果。首次点击“授权自动写回”选择目标 HTML，之后修改自动写入该文件。需要使用支持此文件授权接口的浏览器，例如桌面 Chrome/Edge。

[visual-prd-2.2.0.zip](../dist/visual-prd-2.2.0.zip) 为更新后的技能包。仓库示例使用新格式，不包含旧浏览器草稿中的图片流程图。
