# 可视化 PRD 4.2.2 SkillHub 上传兼容验证

验证日期：2026-11-16。

## 原因与修复

4.2.1 只保证 ZIP 小于 3 MB，仍含两张独立 WebP。用户截图和 SkillHub 当前前端均表明这些二进制扩展名会被跳过，导致资源缺失。

本版将两张图片改为真正的 UTF-8 SVG 文本：在 SVG 的 image 元素中以 data URI 内嵌原始 WebP 字节，保留尺寸与完整内容，不重新绘制、不减色、不降采样。构建器离线内嵌 SVG；图标元数据指向 SVG。无需下载或还原文件，原离线功能保留。

新增 `package-skill.py --skillhub`，上传包根目录直接包含 SKILL.md。所有分发包都检查文本后缀、UTF-8 和空字节，避免再次把独立二进制文件放入上传包。技能标识保持 visual-prd，校验不再依赖平台自行选择的安装目录名称。

## 新鲜验证

- SkillHub 上传包共 61 项，**2,494,754 字节（约 2.49 MB）**，小于 3,000,000 字节。
- 解压后纯文本总量 **5,887,589 字节**，全部可按 UTF-8 解码，无空字节，无命中当前网页禁止扩展名的文件。
- 对照上一版，全部 61 项资源有完整映射；只将两张 WebP 路径替换为对应 SVG，没有删去库、脚本、模板或参考资料。
- 提取 SVG 内的图像，逐字节等于上一版无损 WebP。独立 Chrome 画布测试确认 SVG 与原图渲染 RGBA 逐通道一致，尺寸仍为 1254 × 1254 和 1024 × 1024。
- 离线 HTML Logo 正常解码；原 11 组浏览器回归通过，包括旧草稿、模式切换、独立栏开关、标注文字/图片、七栏目、Mermaid、全屏/PNG、单页/全部页面导出、界面规范、真实文件句柄恢复与已有 HTML 增强交互。
- 完整技能校验、烟雾构建、格式校验、ZIP CRC 通过。上传包最终 61 个文件逐一与定稿源码比较一致，避免交付旧脚本。
- 从上传包解压到非固定名称的安装目录后再运行完整校验与构建，确认没有依赖仓库外的二进制图片。

## 平台校验范围

只读检查了 [SkillHub 官方网页](https://skillhub.cn/) 当前加载的 [公开前端脚本](https://cloudcache.tencent-cloud.com/qcloud/tea/app/skillhub/assets/skill-hub.dc3cj3ht.js?max_age=31536000)：禁止扩展名中包含 .webp、.png、.zip 等，不包含 .svg；当前上限为 200 文件、解压后总量 10,485,760 字节。上传包按这些规则做了本地预检，全部通过。网页规则可能更新，应以实际上传页面为准。
