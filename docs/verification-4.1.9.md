# Visual PRD 4.1.9 评审布局验证

验证日期：2026-10-19。本版仅精简标准评审容器及技能生成约束，未读取或修改用户的软件授权系统项目。

## 布局调整

- Logo 旁只保留主标题，移除副标题；去掉原型上方重复当前页状态行。
- 标题栏下使用全宽页面工具栏：左侧翻页与页面选择，右侧依次为编辑、下载、重新载入。现有项目的评审场景可保留在导航旁。
- 不添加画布/缩放控制、本页需求入口、产品背景尾注；这些项目定制文字不在标准模板中，本版补充了明确生成约束。
- 画布 padding 为零，外框无边框、圆角和阴影；三栏、浮动以及左右栏独立开关后，iframe 填满可用区域。只修改评审容器，不删原型内部业务布局。
