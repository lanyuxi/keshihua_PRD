## 独立复核与修复

独立只读浏览器复核确认并关闭：

- 业务弹层异步隐藏后可见性未及时同步：监听业务 DOM 变化刷新上下文，排除标注运行时自己的 DOM，避免刷新循环；统一 modal、drawer、原生 dialog 与 popover 层级。
- 列表位置选择器在排序后绑错记录：优先使用稳定记录身份，并在必要时限定所属容器。
- 内嵌图临时缩放进入完整图片：克隆 SVG 时移除临时 transform，复核栅格一致。
- 卡片空结果丢失字段锚点：字段说明独立于数据记录保留，维持原编号协议。
- 动态字段标注回流到开发导出：仅对生成器标记的脚本净化标注元数据，业务数据与列定义保留；复核卡片/表格重绘无标注回流。

最终独立复核无阻断项。
