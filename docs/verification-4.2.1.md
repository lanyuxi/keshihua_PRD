# 可视化 PRD 4.2.1 标注操作与阅读验证

验证日期：2026-11-16。

## 本版变化

- 编辑与添加弹窗均有右上角 ×、右下角取消，添加时使用“添加标注”标题。退出继续沿用自动保存，不撤销已输入内容；确定继续等待写回队列。
- 右栏编辑旁增加删除，自定义中文弹窗二次确认。取消不删除，确定后卡片与圆点消失；其他编号不变，新编号不复用已删编号。
- 删除记录只保留原编号、ID、位置等必要元数据并清空正文；原运行时识别明确删除，当前页允许删除产生的编号缺口，重复编号仍拒绝。无删除的模型保留原连续编号校验。
- 页面、路径、标签页/弹层使用中文名称，CSS 选择器和路由 ID 留在内部；无中文名时用中文页面序号，不借用别页名称，不修改业务路由。
- 无内容变化的详情刷新复用正文节点，显式允许文字选择；内容区无动作点击不触发无必要刷新。
- 技能与示例采用通俗中文，必要英文后加括号中文解释；规则集中定义，其他标注不重复复制同一要求。原模型的正式规则、验收依据保持。

## 新鲜验证

八组真实 Chrome 检查全部通过：编辑关闭/取消、添加关闭/取消、鼠标拖选与实际系统复制、中文路径、原有标注确认删除/取消、人工标注删除后保号递增及重载、实际文件写回与无缓存重开/开发导出、无未处理异常。

划选复现区分了触发条件：4.2.0 单独拖选可以保留；追加 AnnotationRuntime.refresh 后选区丢失。4.2.1 在同样的拖选、普通内容点击、无变化刷新后保留选区，系统剪贴板内容与选中文字相同。

原十一组 Chrome 回归通过：旧草稿、评审模式、独立栏开关、标注文字/规则/图片、七栏目、Mermaid 编辑纠错、全屏/缩放/PNG、单页与全部开发导出、界面规范、真实文件句柄恢复、已有 HTML 增强交互。最后的可选中文字样式调整后再次验证划选与构建。

独立只读浏览器复核无阻断：删除原生编号 1 后，2–6 保持不变；详情刷新后选区保留；中文业务页与未知页分别显示真实中文名和“页面 2”，未误用其他页标题。手工标注详情的可见路径也使用中文。
