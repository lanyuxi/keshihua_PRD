# Visual PRD 4.1.7 优化验证

验证日期：2026-10-19。以本仓库 4.1.6 为起点，继续保留用户提供的 4.0.2 原包能力和 2.2.1 新增能力；本次只优化技能，未读取或修改用户的软件授权系统项目。

## 改动与原因

- 默认自适应：原容器仅让 iframe 宽度随画布变化，固定宽度的原型外层布局仍可能保持 1440 px。现在适配评审工作文档中的 html/body 和外层布局根节点，去掉画布最小宽度限制，宽度随栏位和浏览器变化；不对原型整体做缩放，不改业务组件和原始输入文件。非标准布局可在真实外层节点添加 `data-vprd-responsive-root`。原版 `setMode` 函数逐字未改。
- 已有文件直接写回：将另存为接口改为 `showOpenFilePicker`，只选择一个已有 HTML，再请求写权限。取消或拒绝更换保留原写回目标。
- 编辑立即提交保存：移除 320 ms 停止输入等待，保留串行写入，跳过尚未开始的过期版本；只在写入流成功关闭后报告成功。左侧增加“立即保存”，标注“确定”等待写入结果，失败时保留弹窗。
- 标注“确定”位于弹窗右下角，采用蓝色背景、白字；顶部标题栏高度从 58 px 增加为 72 px，保留原有小号操作按钮。
- 产品说明生成约束不再添加“说明来源”“来源于某文件/截图”等过程文案。业务必需的数据来源、流程解释和独立交接材料中的证据追踪仍保留。
- 左上角默认 V 替换为用户提供的玻璃质感 PRD 图片，原图保存在 `assets/brand-logo.png`，构建时内嵌到 HTML。未覆盖原技能图标和原作者署名。

## 保留与边界

原 4.0.2 包的 51 个文件全部保留，其中 40 个逐字节一致；新增 8 个文件，共 59 个。原包 SHA256 仍为 `9820ae72077a9ce56790f10c39323cec4d8cd54d02505ed2c3dca78e64a594c7`，原包 `_meta.json` 未改。产品模型、三种模式、界面规范、需求交接、指标、七个说明栏目、流程图查看和交互页面导出持续保留。

- 原型外层自适应不会自动重设计内部固定尺寸表格或业务组件；非标准外层根节点需要在工作副本上标记并验证。
- 首次磁盘写回仍需用户通过桌面 Chrome/Edge 选择正在编辑的已有 HTML 并授权，未授权时只能保存浏览器草稿；没有宣称浏览器能无授权写入磁盘。
- 评审 HTML 写回不反向修改产品模型、PRD、流程图或标注 JSON 源文件。
- 原包继承的 iframe sandbox 浏览器提示与 Python 构建器转义 SyntaxWarning 单独记录，未扩大修改范围。
- 仓库继续只保留用户此前指定的那一张界面截图；本次 Logo 属于品牌素材，不是新增截图。
