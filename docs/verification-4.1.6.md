- 唯一基底为用户提供的 `visual-prd-aifanche-4.0.2.zip`；原包 SHA256 为 `9820ae72077a9ce56790f10c39323cec4d8cd54d02505ed2c3dca78e64a594c7`，未改变原压缩包。原包正文的 4.1.4 是其自带版本标注差异，不是改用另一基底。
- 原包 51 个文件在增强版全部存在：40 个字节不变，11 个仅为新增能力与兼容性修复修改；新增 6 个配套文件，共 57 个。
- 重新执行原包自带的模板、语法、烟雾构建、产品模型、界面规范、三种模式、零标注与 Axure 壳拒绝、指标检查，8 组均通过。原包缺图标导致的完整包检查问题单独处理，未把这次功能测试称为原包完整打包验证。
- 原版已有的角色与规则栏目内容选取范围、项目标题保留；新增栏目不会删掉原文。
- 已复现并修复 4.1.5 在 IndexedDB 可用时忽略原版 localStorage 草稿的问题：现在同时检查原版草稿、新草稿和文件内状态，按时间选择较新内容。原版模式与有限数值栏宽校验恢复。
- 11 组真实 Chrome 浏览器回归通过；原版草稿、模式与栏宽恢复是新增一组。独立 `check-draft-compatibility.js` 覆盖新旧草稿优先级、磁盘状态优先级、无效模式及栏宽，随技能发布。

## 修复与边界

- 迁入旧版能力时补齐新版界面规范在磁盘 HTML 中的保存恢复。
- 说明章节抽取支持嵌套标题与加粗业务规则块，避免新版模型生成的规则只存在于功能需求而规则栏为空。
- 原包缺失的图标采用用户提供的旧原作者包中的 1024×1024 图标；保留作者署名，增强版版本为 4.1.6。原包 `_meta.json` 已逐字节恢复，其中 4.0.2 是原包的发布元数据，不代表增强版版本。
- 浏览器记录到原版 iframe 的 `allow-scripts` 与 `allow-same-origin` 组合警告，单独记录；未改动其信任边界。构建器原有 Python 转义 SyntaxWarning 仍在，未扩大修改范围。
- HTML 评审修改不反向更新 product-model.json、prd.md、flows.md 或 annotations.json；正式源文件变更需回写并重建。
- 已有多页 HTML 需要能枚举页面和导航的适配协议；依赖外部页面、接口或 Axure 多文件入口不能假称已全部离线导出。
- 本记录对应 4.1.6 发布文件；实际磁盘授权仍由打开 HTML 的浏览器管理。
